Multi-Agent 系统架构

任务编排器 → 工具调用 → 上下文管理 → 记忆系统 → 人机协同 · 数据流 + 控制流

控制流（Control Flow）

  • 用户 → Gateway（鉴权后转发）
  • Gateway → Orchestrator（意图解析）
  • Orchestrator → Tool Router（LLM 决策选工具）
  • Tool Router → Tools（Function Calling）
  • Orchestrator → Human Confirm（敏感操作搁置）
  • 用户确认 → Tool Router 放行

数据流（Data Flow）

  • Context 注入 → Orchestrator（对话历史）
  • Memory 检索 → Orchestrator（长期记忆）
  • Tools → Orchestrator（执行结果回传）
  • Orchestrator → Response（汇总生成）
  • Response → Gateway → User（SSE 流式推送）

三层记忆体系

  • 短期：内存中的当前对话窗口（最近N轮）
  • 中期：Redis 存储会话状态（TTL过期）
  • 长期：向量数据库（ChromaDB/PGVector）存嵌入+摘要
  • 上下文压缩：token 不够时，旧对话→LLM 摘要→替代原始

安全 & 容错设计

  • 敏感操作（发邮件/删数据）→ 人机确认
  • 工具调用失败 → 指数退避重试 3 次
  • 某步骤多次失败 → 降级策略 / 跳过错步
  • 整个任务失败 → 保存中间状态，可从断点恢复
