# Blender 入门：今天学到的简单指令

日期：2026-09-07。练习项目：为 1 对 1、2.5D 龙珠对打游戏制作悟空人物。当前是身体比例基础模型，还没有完成头发、五官和服装。

## 什么是简单交互

一次只做一个动作，例如选择、放大、切换视角、移动。采用人机交替练习：AI 演示并解释 → 人操作 → AI 检查画面 → 再进入下一步。

## 今日操作速查

先切换到英文输入法；快捷键要在鼠标位于 3D 视图时使用。只移动鼠标过去，不要再单击模型，否则会改变选区。Mac 的 Option 键对应 Alt。

| 想做什么 | 简单操作 | 会看到什么／作用 |
| --- | --- | --- |
| 选择一个身体部件 | 鼠标左键单击头部或躯干 | 出现橙色轮廓，表示选中了这个物体 |
| 拉近观察 | 鼠标滚轮向上滚动 | 画面放大，模型实际尺寸不变 |
| 看右侧面 | 点击视图右上角坐标指示器的红色 X | 切换到右侧视图；本模型面朝屏幕左边 |
| 编辑头部形状 | 选中头部，左上角 Object Mode → Edit Mode | 出现组成头部的点和线；Tab 也可切换模式 |
| 取消选择 | Option + A | 顶点变暗；只是取消选择，没有删除模型 |
| 开关透视选择（X-Ray） | Option + Z | 模型半透明，可选中被表面遮挡的顶点 |
| 框选一组点 | 使用左侧框选工具，在空白处按住左键拖出方框 | 框内顶点变橙色；开启透视选择可选到背面的点 |
| 将观察中心对准选中部分 | View → Frame Selected | 视图对准选中的部分，模型形状不变 |

## 下巴底部如何框选

1. 保持编辑模式和透视选择开启。
2. 鼠标位于视图内，按 Option + A 取消选择。
3. 使用左侧框选工具，从最底下一排点的左上方空白处，按住左键拖到右下方空白处，再松开。
4. 只包住最底下一排点，不要包住上一排；底部整排变橙色表示选中。
5. 如果 AI 已经选好，直接继续移动，不要再点击模型。

## 移动下巴（已完成并检查）

准备：在头部编辑模式下，开启透视选择，只框选下巴底部的一圈点。

依次按 **G → Y → 输入 -0.015 → 回车**，不用同时按。

- G：移动。
- Y：只沿 Y 轴移动；在当前模型中是前后方向。
- -0.015：沿负 Y 方向移动 0.015 个 Blender 单位；当前右侧视图里表现为向左移动一点。
- 回车：确认移动。

这个数值只用于当前基础模型，不是所有人物通用的数值。操作后要检查侧面轮廓再继续。

## 操作失误怎么办

- 还没确认移动：按 Esc 取消。
- 已确认但移动错了：菜单 Edit → Undo 撤销上一步。
- 本次检查发现误选了脸侧单个点，AI 已撤销移动并重新框选下巴底部整圈。随后通过 Move 面板修改 Y 数值，已完成移动并检查。

## 记住三个区别

- 物体模式选的是整个部件；编辑模式选的是部件上的顶点。
- 调整视图只是换观察方式；移动顶点才会改变模型形状。
- 透视选择（X-Ray）方便选到背面的点，并不是切换透视投影。
